# Приглашение · 2-ой Кубок Президента Республики Таджикистан

Трёхъязычная (RU / TJ / EN) страница-приглашение на торжественную церемонию
открытия Международного шахматного турнира «2-ой Кубок Президента Республики
Таджикистан».

**10 ноября 2026, 13:00 · зал «Istiqlol», отель Crowne Plaza, Душанбе**

## Что внутри

- `index.html` — вся страница одним файлом: вёрстка, стили и скрипт переключения языков
- `logos/` — эмблемы организаторов и вырезанный национальный орнамент для фона

Переключатель РУС / ТОҶ / ENG запоминает выбор в `localStorage`.
В шапке показывается, сколько дней осталось до церемонии.

## Как открыть

Достаточно открыть `index.html` в браузере — внешних зависимостей нет,
кроме шрифтов Google Fonts (Cormorant Garamond, Manrope, JetBrains Mono).

## Фирменные элементы

- фон — #5A078D
- акцент — #F2C94C
- орнамент на фоне вырезан из национального узора, перекрашен в белый с прозрачностью
